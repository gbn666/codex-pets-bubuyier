# Usage

Each pet folder contains a Codex-compatible `pet.json` and `spritesheet.webp`.

To install one pet locally:

1. Copy `pets/yier` or `pets/bubu` into `%USERPROFILE%\.codex\pets\`.
2. Restart Codex.
3. Select the pet from Codex's pet picker if required by your app version.

The animation atlas follows the hatch-pet row layout:

| Row | State |
| --- | --- |
| 0 | idle |
| 1 | running-right |
| 2 | running-left |
| 3 | waving |
| 4 | jumping |
| 5 | failed |
| 6 | waiting |
| 7 | running |
| 8 | review |
