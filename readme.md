# 一二与布布 Codex Pets

这是一个基于“一二”和“布布”形象制作的 Codex 自定义桌宠项目。项目将两个软萌风格的角色转化为适用于 Codex 的桌面宠物，使其能够在 Codex 环境中以轻量、可爱、陪伴式的方式出现。

## 项目简介

本项目包含两个自定义 Codex 宠物角色：

- **一二**：白色圆润身体、深棕色耳朵、粉色腮红和软萌表情，整体性格偏害羞、温柔、委屈巴巴。
- **布布**：奶茶棕色小熊形象，性格更加慵懒、治愈、呆萌，适合作为轻松陪伴型桌宠。

两个角色整体采用统一的软萌吉祥物风格，强调简洁轮廓、低饱和配色、扁平化表现和桌面宠物可读性。

## Features

- Custom Codex desktop pet design
- Soft chibi-style character appearance
- Pixel-art-adjacent visual style
- Simple and readable sprite-friendly design
- Idle, greeting, sleepy, shy, eating, phone-checking and companion-style action ideas
- Designed for personal customization and lightweight desktop companionship

## Character Design

### 一二

一二是一个害羞、柔软、治愈感较强的白色小熊/团子形象。它的核心视觉特征包括：

- 圆润白色身体
- 深棕色圆耳朵
- 粉色腮红
- 小圆眼睛
- “w”形小嘴
- 微微担心或害羞的眉毛
- 小巧柔和的身体比例

### 布布

布布是一个奶茶棕色的软萌小熊形象，整体气质更加慵懒、放松和呆萌。它的核心视觉特征包括：

- 奶茶棕色圆润身体
- 深棕色描边
- 小熊耳朵
- 黄色系腮红
- 困困的表情
- 可选的小帽子、斜挎包、饮料或信封道具

## Usage

This project is intended to be used with Codex custom pets.  
You can use the provided character references and prompts with the `hatch-pet` skill to generate a Codex-compatible pet package.

Basic workflow:

1. Install the `hatch-pet` skill in Codex.
2. Upload the character reference images.
3. Use the provided prompts to generate the pet.
4. Review and repair the generated pet if needed.
5. Refresh custom pets in Codex settings.
6. Select and enable the custom pet.

## Suggested Pet Behaviors

The pets are designed around soft and simple desktop interactions, such as:

- idle blinking
- gentle breathing
- tiny body sway
- shy hand motion
- small friendly wave
- sleepy yawn
- holding a phone
- eating noodles
- holding a drink
- sitting quietly
- keeping company
- paired companion interactions

## Project Goal

The goal of this project is to create a pair of cute, recognizable and emotionally expressive Codex desktop pets.  
Instead of focusing on complex animation or highly detailed illustration, the design prioritizes:

- recognizability at small size
- simple expressive actions
- soft emotional personality
- compatibility with Codex pet style
- consistent visual identity between characters
